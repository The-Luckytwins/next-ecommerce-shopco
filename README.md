# Lady Porsh — Beauty & Cosmetics Storefront

Lady Porsh is a responsive cosmetics storefront built with Next.js 14 App Router, TypeScript, Tailwind CSS, Redux Toolkit, Framer Motion, and reusable UI components.

The original storefront structure is retained while its visual identity, copy, catalog, imagery, categories, product options, metadata, and footer credit have been adapted for a beauty brand.

## Storefront features

- Responsive homepage, navigation, category browsing, and product listing.
- Beauty-focused sample catalog with product images, prices, ratings, descriptions, and gallery views.
- Product detail pages with shade and format selections.
- Redux-powered cart with quantity controls, variant-aware cart items, discounts, and order summary.
- Product filters, sorting controls, FAQ and review sections.
- Cosmetics-focused metadata, favicon, and brand styling.
- Responsive layout and animated section transitions.

## Technology

- Next.js 14 App Router
- React and TypeScript
- Tailwind CSS
- Redux Toolkit and Redux Persist
- Framer Motion
- Radix UI / shadcn-style components

## Run locally

1. Install Node.js and npm.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000` in your browser.

Use `npm run build` to create a production build.

## Notes

- Catalog entries, prices, ratings, and customer reviews are demonstration content. Replace them with Lady Porsh's verified inventory and genuine customer feedback before launch.
- Product photography is loaded from Unsplash-hosted image URLs, so an internet connection is required to display those images.
- This repository is a front-end storefront. Confirm the real inventory, checkout, delivery, returns, and payment workflows before accepting live orders.
